## Что нового

- **Браузер обновляется сам.** Новые версии скачиваются с GitHub в фоне и ставятся при следующем запуске; в меню ⋮ появляется «Перезапустить и обновить». Выключается в «Настройках» → «Обновления».
- **Перевод выделенного текста:** правый клик по выделению → «Перевести «…»», перевод появляется в окошке рядом с текстом.
- Загрузки больше не «качаются вечно»: закрытие вкладки или её сон не обрывает загрузку и не оставляет её висеть в списке. Вкладка, открытая только ради скачивания файла, закрывается сама.
- История открывается при любом её размере. Раньше большая история не открывалась, а вкладки после этого становились «мёртвыми».
- Меньше подтормаживаний: быстрое переключение между вкладками больше не перерисовывает страницу заново, полоса вкладок не отпрыгивает к активной, меню у загрузки не закрывается само.

Это обновление нужно поставить вручную, запустив новый **MBrowser-Setup.exe** поверх старой версии (настройки, вкладки и профиль сохранятся). Дальше браузер будет обновляться сам.

## Как установить

1. Скачайте **MBrowser-Setup.exe** ниже (раздел Assets) и запустите.
2. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите **«Подробнее» → «Выполнить в любом случае»**. Окно появляется потому, что установщик не подписан сертификатом.
3. Права администратора не нужны: браузер ставится только для вашего пользователя.

В конце установки можно сразу сделать Meteor Browser браузером по умолчанию.

Нужен Microsoft Edge WebView2 Runtime. В Windows 11 он уже есть, в Windows 10 обычно тоже; если нет, установщик предложит его скачать.

**mbrowser.exe** — тот же браузер без установщика: один файл, можно запускать из любой папки.

Удаление: «Параметры» → «Приложения» → Meteor Browser. Настройки и профиль при этом не удаляются.
