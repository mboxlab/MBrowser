## Что нового

- `Ctrl+Shift+T` возвращает закрытую вкладку вместе с историей: кнопки «Назад» и «Вперёд» снова ведут на страницы, открытые в ней раньше (до 10 назад и 5 вперёд).
- Эта история больше не пропадает у уснувших вкладок и сохраняется между запусками браузера.
- Перенос данных из Яндекс Браузера: `tools\import_yandex.py` (вкладки, Табло, закладки, история, пароли, расширения). Подробности — в README.

Чтобы обновиться, запустите новый **MBrowser-Setup.exe** поверх старой версии: настройки, вкладки и профиль сохранятся.

## Как установить

1. Скачайте **MBrowser-Setup.exe** ниже (раздел Assets) и запустите.
2. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите **«Подробнее» → «Выполнить в любом случае»**. Окно появляется потому, что установщик не подписан сертификатом.
3. Права администратора не нужны: браузер ставится только для вашего пользователя.

В конце установки можно сразу сделать Meteor Browser браузером по умолчанию.

Нужен Microsoft Edge WebView2 Runtime. В Windows 11 он уже есть, в Windows 10 обычно тоже; если нет, установщик предложит его скачать.

**mbrowser.exe** — тот же браузер без установщика: один файл, можно запускать из любой папки.

Удаление: «Параметры» → «Приложения» → Meteor Browser. Настройки и профиль при этом не удаляются.
