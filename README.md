# Meteor Browser

Быстрый и лёгкий браузер для Windows. Оболочка написана на Rust (exe ~4 МБ, ~20 МБ памяти,
из них ~12 МБ — скомпилированные списки фильтров блокировщика),
страницы рисует системный движок **WebView2** — тот же Chromium, что в Edge. Он уже есть в
Windows 10/11, поэтому сайты работают так же, как в Chrome/Edge.

## Установка

Скачайте **[MBrowser-Setup.exe](https://github.com/mboxlab/MBrowser/releases/latest/download/MBrowser-Setup.exe)**
(все версии — на странице [Releases](https://github.com/mboxlab/MBrowser/releases)) и запустите.
Права администратора не нужны. Установщик не подписан, поэтому Windows может показать
«Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

## Почему быстро

- **Вкладки засыпают.** При запуске восстановленные вкладки не грузятся — только активная.
  Фоновые вкладки через 15 минут засыпают и освобождают память. Вкладки со звуком,
  закреплённые и приватные не усыпляются.
- **Скрытые вкладки** сразу переводятся в режим экономии памяти WebView2.
- **Встроенный блокировщик рекламы уровня uBlock Origin** (движок Brave, adblock-rust). Он
  понимает синтаксис uBlock Origin и AdBlock Plus и работает со списками uBlock Origin
  (фильтры, приватность, вредоносные сайты, исправления), EasyList, EasyPrivacy и RU AdList.
  - Запросы рекламы и трекеров не уходят в сеть, поэтому страницы грузятся быстрее. Вместо
    рекламных скриптов, которые нужны сайтам для работы (Google IMA, GPT…), подставляются
    безвредные заглушки uBO.
  - Рекламные блоки скрываются, включая процедурные фильтры (`:has-text`, `:upward`,
    `:remove()`…).
  - Скриптлеты uBO (`+js(...)`) запускаются раньше скриптов страницы. На них держится борьба
    с рекламой на YouTube и с «выключите блокировщик».
  - Списки обновляются сами раз в 4 дня в фоне. Скомпилированный движок лежит на диске и при
    запуске загружается за ~3 мс.

  Щит в панели показывает, сколько заблокировано; клик по нему выключает блокировку на текущем
  сайте. Меню ⋮ → «Блокировка рекламы»: общий выключатель, скрытие окон о cookie (включено) и
  раздражающих элементов, SponsorBlock, обновление фильтров, свои правила.
- **SponsorBlock.** На YouTube спонсорские вставки, самореклама и просьбы подписаться
  пропускаются сами, а на полосе прогресса они отмечены цветом. Плашка «Пропущено · Отменить»
  возвращает назад. Работает по базе [sponsor.ajay.app](https://sponsor.ajay.app): уходят только
  4 символа хеша ID видео.
- **Перевод страниц.** На странице не на русском в адресной строке появляется кнопка перевода
  (она же есть в меню ⋮). Переводится то, что видно на экране, остальное по мере прокрутки.
  Новые страницы в этой вкладке тоже переводятся, пока перевод не выключен («Показать
  оригинал»). Перевод делает Google Translate.
- **Закадровый перевод видео (VOT).** Расширение [Voice Over Translation](https://github.com/ilyhalight/voice-over-translation)
  — озвучка иностранных видео от Яндекса (YouTube и ещё ~180 сайтов) — ставится само при первом
  запуске и обновляется из его релизов на GitHub (проверка раз в 6 часов: Яндекс часто меняет API,
  и старые версии перестают работать). Если удалить его в меню ⋮ → «Расширения», обратно оно
  не ставится.
- **Предзагрузка из Табло.** Пока открыто Табло, браузер заранее устанавливает соединения с его
  сайтами и держит наготове скрытую вкладку. Если задержать курсор на плитке (~0,1 с), сайт
  начинает грузиться ещё до клика, а по клику эта вкладка просто показывается.
- **Мгновенный старт**: окно с активной вкладкой появляется за ~0,4 с.

## Возможности

- Вкладки прямо в заголовке окна, без системной полосы с дублирующимся названием. Окно таскается
  за пустое место рядом с вкладками, двойной клик разворачивает; работают снап и ресайз за края.
- «+» и `Ctrl+T` открывают не пустую вкладку, а Табло поверх размытой страницы: плитки ваших
  сайтов (правый клик по фону: «Настроить Табло», размер плиток, ширина). Набранный адрес
  открывается в новой вкладке, `Esc` закрывает Табло. Кнопка «Загрузки» открывает список прямо
  поверх Табло, не закрывая его.
- Пространства: отдельные наборы вкладок («Основное», «Работа»…) со своим цветом — он
  подкрашивает полосу вкладок. Кнопка слева от вкладок открывает панель (создать, переименовать,
  сменить цвет, удалить), колесо мыши над ней листает пространства, `Ctrl+Shift+1…9` переключает.
  Вкладку можно перенести в другое пространство через правый клик.
- Адресная строка с подсказками из истории, закладок и открытых вкладок («Перейти на вкладку»),
  автодополнение часто посещаемых сайтов.
- Новая вкладка: часы, поиск, плитки самых посещаемых сайтов.
- История (`Ctrl+H`) с поиском; закладки (`Ctrl+D`, звёздочка в адресной строке).
- Страница «Закладки» (`Ctrl+Shift+O`, `mb:bookmarks`): поиск, переименование, удаление с отменой,
  порядок перетаскиванием; средний клик открывает в новой вкладке.
- Страница «Настройки» (меню ⋮, `mb:settings`): поисковик, блокировка рекламы и её списки, защита от
  слежки, сон вкладок, восстановление сессии, язык перевода, SponsorBlock, Табло, папка данных.
  Изменения применяются сразу и пишутся в `settings.json`. Менять настройки и закладки могут
  только эти внутренние страницы (случайный токен на запуск), обычные сайты — нет.
- Приватные вкладки (`Ctrl+Shift+N` или правый клик по `+`).
- Закрепление и выключение звука вкладок, перетаскивание, «закрыть другие / справа»
  (правый клик по вкладке).
- Восстановление закрытых вкладок (`Ctrl+Shift+T`) вместе с историей «назад / вперёд» (до 10 / 5
  страниц) — она же сохраняется у уснувших вкладок и в сессии. При запуске восстанавливаются
  сессия, размер и положение окна.
- Полноэкранный режим (`F11`) и полноэкранное видео.
- Выбор поисковика: Google, Яндекс, DuckDuckGo, Bing (меню ⋮).
- Поддержка расширений Chrome, например uBlock Origin Lite (см. ниже).
- Ссылку или файл можно перетащить на полосу вкладок — откроется новая вкладка.

## Сборка

Нужны Rust (тулчейн MSVC) и WebView2 Runtime (в Windows 11 уже установлен).

```
cargo build --release
```

Результат — `target\release\mbrowser.exe`, один файл, его можно скопировать куда угодно.
`mbrowser.exe https://example.com` открывает ссылку в новой вкладке.
Внутреннее короткое имя — `mbrowser` (M — Meteor): так называются exe, папки с данными и
переменные окружения.

Установщик собирается [Inno Setup 6](https://jrsoftware.org/isinfo.php) из
`installer\mbrowser.iss` (`iscc /DAppVersion=0.1.0 installer\mbrowser.iss` → `dist\MBrowser-Setup.exe`).
Он ставит exe туда же, куда пункт меню «Установить…», и пишет те же ключи `HKCU`, так что они
друг другу не мешают.

Релиз: поднять `version` в `Cargo.toml`, закоммитить и запушить тег `v<версия>`
(`git tag v0.2.0 && git push origin v0.2.0`). GitHub Actions (`.github/workflows/release.yml`)
соберёт браузер и установщик, проверит установку и удаление и опубликует релиз с
`MBrowser-Setup.exe` и `mbrowser.exe`. Текст релиза — `installer\release-notes.md`.

Иконка (`assets\mbrowser.ico`, плюс PNG 256/512/1024) рисуется скриптом
`python tools\make_icon.py` (нужны numpy и Pillow); `build.rs` вшивает её в exe.

## Браузер по умолчанию и один экземпляр

Меню ⋮ → «Установить и сделать браузером по умолчанию»: копирует exe в
`%LOCALAPPDATA%\Programs\MBrowser\mbrowser.exe`, создаёт ярлыки «MBrowser» в меню «Пуск» и на
рабочем столе и регистрирует браузер для текущего пользователя (ветка `HKCU`, права администратора не нужны:
`Software\Clients\StartMenuInternet\MBrowser`, `RegisteredApplications`, ProgID `MBrowserURL`,
`MBrowserHTML`, `MBrowserPDF` для http/https, .htm/.html/.xhtml/.pdf). После этого открывается
страница Windows «Приложения по умолчанию» — выбрать MBrowser должен сам пользователь (Windows не
позволяет сделать это программно). Повторная установка обновляет копию; если установленная копия
сейчас запущена, она заменяется со следующего запуска.

Меню ⋮ → «Удалить установку и регистрацию браузера»: убирает регистрацию, ярлыки и установленную
копию; настройки и профиль не трогаются.

Один экземпляр на профиль: повторный запуск (клик по ссылке, `mbrowser.exe URL`, файл `.html`)
не открывает второй браузер, а передаёт адрес работающему — тот открывает его в новой вкладке и
выходит на передний план. Профили с разным `MBROWSER_HOME` независимы. Пути к файлам
(`C:\x\a.html`) превращаются в `file://`-адреса.

Для проверок: `MBROWSER_REG_ROOT=Software\MBrowserTest` переносит все записи реестра в эту ветку
`HKCU`, `MBROWSER_INSTALL_DIR=<папка>` меняет папку установки; в этом режиме нет ярлыков, окон
сообщений и страницы настроек Windows.

## Браузер по умолчанию и один экземпляр

Меню ⋮ → «Установить и сделать браузером по умолчанию»: exe копируется в
`%LOCALAPPDATA%\Programs\MBrowser\mbrowser.exe`, появляются ярлыки «MBrowser» в меню «Пуск» и на рабочем столе, а
для текущего пользователя (HKCU, права администратора не нужны) регистрируются браузер
(`Software\Clients\StartMenuInternet\MBrowser`, `RegisteredApplications`) и обработчики
`http`/`https`, `.htm`/`.html`/`.xhtml`/`.pdf`. Затем открывается «Приложения по умолчанию»:
Windows не позволяет программе назначить себя сама, там нужно выбрать MBrowser. Если браузер
уже запущен из установленной папки, копирование пропускается; занятый файл заменяется на лету.
Обновление: запустить новую версию и снова выбрать этот пункт.
«Удалить установку и регистрацию браузера» убирает ярлыки, ключи реестра и установленную копию
(настройки и профиль не трогаются).

Запуск ссылки или файла (`mbrowser.exe https://…`, `mbrowser.exe C:\x\a.html`, клик по ссылке
в другой программе) при уже работающем браузере открывает вкладку в нём и выводит окно на
передний план, второй процесс сразу завершается. Экземпляр один на профиль (папку данных), поэтому
`MBROWSER_HOME` даёт независимый браузер. Для проверок: `MBROWSER_REG_ROOT=Software\MBrowserTest`
переносит все записи реестра в этот раздел HKCU, `MBROWSER_INSTALL_DIR=<папка>` — папку установки
(ярлыки и окна сообщений в этом режиме отключены).

## Настройки и данные

`%APPDATA%\MBrowser\` (меню ⋮ → «Папка настроек и блок-листа»):

- `settings.json` — поисковик, блокировщик, время до сна вкладок (`sleep_minutes`, `0` — никогда),
  уровень защиты от слежки (`tracking_prevention`: `none` / `basic` / `balanced` / `strict`).
  Для блокировщика: `adblock_lists` — свои списки фильтров (URL), `sponsorblock_categories` — что
  пропускать (`sponsor`, `selfpromo`, `interaction`, `intro`, `outro`, `preview`,
  `music_offtopic`, `filler`), `translate_to` — язык перевода.
- `blocklist.txt` — свои правила (меню ⋮ → «Блокировка рекламы» → «Мои фильтры…»). Понимает
  домены, формат hosts (`0.0.0.0 ads.site.com`), `domain/путь` и любые правила uBlock Origin /
  AdBlock Plus (`||site^$third-party`, `site.com##.banner`, `site.com##+js(...)`). Можно
  вставить целый список, например [StevenBlack/hosts](https://github.com/StevenBlack/hosts).
  Изменения подхватываются сами в течение минуты.
- `extensions\` — распакованные расширения Chrome, по одной папке на расширение (внутри должен
  быть `manifest.json`), например Tampermonkey. Установленные расширения видны в
  меню ⋮ → «Расширения»: там их можно выключить, открыть их настройки (например, панель
  Tampermonkey) или удалить (папка уходит в Корзину). Расширения со своим окошком (SponsorBlock,
  Tampermonkey…) получают значок на панели справа от адресной строки: клик открывает их окно,
  как в Chrome и Vivaldi. Окно видит текущую вкладку, клик мимо или `Esc` закрывает его.
- `history.json`, `bookmarks.json`, `session.json` — история, закладки, открытые вкладки.

Профиль движка (cookies, кэш) лежит в `%LOCALAPPDATA%\MBrowser\Engine`, списки фильтров и
скомпилированный движок блокировщика — в `%LOCALAPPDATA%\MBrowser\Adblock`.

## Перенос из Vivaldi

```
python tools\import_vivaldi.py --dry-run   # показать, что будет перенесено
python tools\import_vivaldi.py             # перенести
```

Оба браузера должны быть закрыты, MBrowser хотя бы раз запущен. Переносятся: вкладки с рабочими
пространствами (имена и эмодзи), пароли, cookies (сайты остаются залогинены), закладки, плитки
Экспресс-панели (в Табло, без рекламных плиток Vivaldi), история и включённые расширения вместе с
их данными. Перед записью всё, что меняется, копируется в `%APPDATA%\MBrowser\backup-<время>`.
Повторный запуск дубликатов не создаёт. Нужен только Python 3.8+ без дополнительных пакетов.

## Перенос из Яндекс Браузера

```
python tools\import_yandex.py --dry-run   # показать, что будет перенесено
python tools\import_yandex.py             # перенести
```

То же самое, что и для Vivaldi (оба браузера закрыты, MBrowser хотя бы раз запущен), с поправкой
на устройство Яндекса: группы вкладок становятся пространствами, Табло переносится без рекламных
плиток Яндекса, из закладок и расширений берётся включённое. Пароли Яндекс шифрует своим ключом
поверх системного — скрипт его достаёт сам; если в Яндексе включён мастер-пароль, пароли не
переносятся, и об этом будет сказано в отчёте (остальное перенесётся). Общий код обоих переносов —
в `tools/browser_import.py`.

Переменная `MBROWSER_HOME=<папка>` держит всё (настройки и профиль движка) в одной папке —
портативный режим или отдельный профиль для экспериментов.

Чтобы посмотреть, что грузит сайт, запустите с переменной `MBROWSER_DEBUG=1`: каждый запрос
печатается как `allow` / `BLOCK` / `REDIRECT` — по этому выводу удобно дописывать правила в
`blocklist.txt`.

## Устройство кода

| Файл | Что делает |
|---|---|
| `src/main.rs` | Цикл событий |
| `src/app.rs` | Ядро: вкладки, сон, раскладка, нативные меню, сессия |
| `src/tab.rs` | Создание WebView2 и нативные хуки (клавиши, фавиконки, звук, полный экран, блокировщик) |
| `src/blocker.rs` | Блокировщик: списки, обновление, движок adblock-rust, скриптлеты uBO |
| `src/content.js` | Скрипт в страницах: скрытие элементов, SponsorBlock, перевод |
| `src/translate.rs` | Перевод страниц (Google Translate) |
| `src/defext.rs` | Расширения по умолчанию (VOT): установка и обновление из релизов GitHub |
| `src/net.rs` | HTTP-клиент на WinHTTP (без лишних зависимостей) |
| `src/omni.rs` | Адресная строка: адрес или поиск, подсказки, автодополнение |
| `src/pages.rs` | Страницы новой вкладки и истории |
| `src/internal.rs` | Страницы «Закладки» и «Настройки» и проверка того, что они могут менять |
| `src/shell.rs` | Один экземпляр на профиль (именованный канал), установка и регистрация браузера в Windows |
| `src/store.rs` | Настройки, история, закладки и сессия на диске |
| `src/ui.html` | Интерфейс: полоса вкладок, адресная строка |
| `tools/import_vivaldi.py` | Перенос данных из Vivaldi |
| `tools/import_yandex.py` | Перенос данных из Яндекс Браузера |
| `tools/browser_import.py` | Общий код переноса (шифрование, cookies, закладки, история, сессия) |
